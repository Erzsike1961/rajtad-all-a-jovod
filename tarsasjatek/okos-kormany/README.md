# 🛞 Okos-Kormány pályaszett

## A fejlesztés célja

Interaktív, mágneses oktatóeszköz létrehozása, amely játékos formában tanítja a gyermekeket a biztonságos közlekedésre.

## A készlet tervezett elemei

- Gyermekméretű tanulókormány
- Mágneses közlekedési pályák
- Közlekedési jelzések
- Feladatkártyák
- Játékos útvonaltervezési feladatok
- Használati útmutató

## Digitális összekapcsolás

A későbbiekben az Okos-Kormány a digitális oktatójátékkal is összekapcsolható.

A gyermek a fizikai eszköz használata közben digitális feladatokat is megoldhat.

## Célcsoport

6–12 éves gyermekek.

## Küldetés

A közlekedési szabályok gyakorlati, élményalapú elsajátítása.
