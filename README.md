# 🚦 Rajtad áll a jövőd!

## Játékos közlekedésbiztonsági oktatóprogram 6–12 éves gyermekeknek

### A projekt célja

A gyermekek biztonságos közlekedésre nevelése játékos, élményalapú és interaktív módszerekkel.

A program a gyalogos, kerékpáros és mikromobilitási közlekedési helyzeteket dolgozza fel.

### A projekt fő elemei

- KRESZ társasjáték
- 30 közlekedési helyzetkártya
- Mágneses Okos-Kormány pályaszett
- Játékos feladatok és kihívások
- Elsősegélynyújtási ismeretek
- Nyomtatható oktatási segédanyagok

### Célcsoport

6–12 éves gyermekek, pedagógusok és családok.

### Küldetésünk

Megtanítani a gyermekeket arra, hogyan közlekedjenek önállóan, tudatosan és biztonságosan.

**Rajtad áll a jövőd!**
